# 말씀 노트 개발 저널 — 개요

> 이 저널은 "무엇을 만들었나"보다 **"왜 그렇게 결정했나"**를 기록한 학습 자료입니다.
> 개발을 배우는 사람이 시니어 개발자의 사고 과정(선택지 비교 → 트레이드오프 → 결정 → 검증)을 따라가며 읽을 수 있게 썼습니다.
> 실수와 삽질도 숨기지 않았습니다. 디버깅 능력은 남의 실수를 읽으면서도 자랍니다.

## 프로젝트 한 줄 요약

개역한글·AMP·MSG·NIV를 읽고, 주제로 성구를 찾고, 영어 본문의 **한글 번역을 엔진별(Google v2 · v3 · Claude)로 나란히 비교**하고, 직접 넣은 본문을 **토씨 하나까지 암송**하는 개인용 성경 웹앱.
Claude Code와의 대화만으로 이틀(2026-10-20 ~ 21) 동안 만들었고, [jj-nini.github.io/bible-notes](https://jj-nini.github.io/bible-notes/)에 배포되어 있습니다.

요구사항과 기술 설계 전체는 [`../prd-trd.md`](../prd-trd.md)에 있습니다.

### 읽는 순서

- **처음 읽는다면:** 01 → 02 → 05 순서로 읽으세요. 프로젝트의 큰 결정 세 가지가 들어 있습니다.
- **디버깅을 배우고 싶다면:** 03 → 04 → 05의 "겪은 문제" 절만 골라 읽어도 됩니다.
- **보안이 궁금하다면:** 02의 RLS, 05의 API 키 노출 사고, 07의 공개 전 점검을 보세요.
- **알고리즘이 궁금하다면:** 08의 오답 생성 규칙과 LCS 채점을 보세요.

### 각 문서의 구성

모든 저널은 같은 틀을 따릅니다.

1. **배경**: 그 시점에 무엇을 하려 했나
2. **결정과 비교**: 선택지 비교표와 트레이드오프
3. **코드로 보기**: 실제 코드와 설명
4. **겪은 문제와 해결**: 증상 → 가설 → 확인 → 원인 → 해결
5. **배운 것**: 주니어 관점 / 시니어 관점
6. **참고 자료**
